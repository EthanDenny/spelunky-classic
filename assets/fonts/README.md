# UI font

The interface uses proportional `NotoSans-Regular.ttf` from the Noto Fonts project.
`NotoSansMono-Regular.ttf` is registered only as a fallback for symbols absent from
the proportional face. Both are bundled so the LÖVE build renders consistently
without depending on fonts installed on the host system.

Noto Sans is distributed under the SIL Open Font License 1.1. The complete
license is included in `OFL.txt`.

Source: <https://github.com/notofonts/noto-fonts/tree/main/hinted/ttf/NotoSans>
